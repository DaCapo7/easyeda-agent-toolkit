# 选型调研任务书（模板）

用法：把整份模板复制给任意一个具备联网检索能力的 AI，填好〈尖括号〉里的内容，删掉填不上的可选项。
本模板不依赖任何特定 AI 产品，也不假设执行者了解你的项目。

---

## 角色

你是电子元器件选型调研员。你的任务是根据下面给出的需求规格，检索出可采购的具体型号，
并以可核验的证据支撑每一个推荐。

你不了解这个项目的任何背景，也不需要了解。需求规格里没写的约束，一律不要自行假设；
遇到影响结论的空缺，在输出末尾的「待确认问题」里列出来，不要用猜测填补。

---

## 需求规格

### 器件用途

〈一句话说明这个器件在电路里做什么，例如：为 3.3V 数字域提供 LDO 稳压〉

### 电气参数

| 项目 | 要求 |
|---|---|
| 关键参数 1 | 〈参数名与取值范围，例如：输出电压 3.3V ±2%〉 |
| 关键参数 2 | 〈例如：连续输出电流 ≥ 500mA〉 |
| 关键参数 3 | 〈例如：输入电压 4.5–12V〉 |
| 其它电气约束 | 〈例如：静态电流 < 50µA；PSRR ≥ 60dB @1kHz〉 |

### 封装与机械

- 封装要求：〈例如：SOT-23-5 或 SOT-89，优先前者；或"不限，但高度 ≤ 1.2mm"〉
- 引脚间距下限：〈例如：≥ 0.5mm，受限于板厂工艺〉
- 占板面积上限：〈例如：3mm × 3mm〉

### 环境与等级

- 工作温度范围：〈例如：−20 ~ +85 °C〉
- 认证 / 等级要求：〈例如：AEC-Q100；或"无特殊要求"〉

### 成本

- 单价上限：〈例如：≤ 1.5 元 @100 片〉
- 目标批量：〈例如：首批 50 片，量产 2000 片/年〉

### 装配工艺约束

- 目标产线：〈例如：嘉立创 SMT 贴片打样〉
- 工艺形式：〈例如：全 SMD，不接受插件；或"允许少量手焊插件"〉
- 库别偏好：〈例如：优先嘉立创**基础库**，扩展库需说明额外上料费是否可接受〉

> **为什么要问库别。** 在嘉立创 SMT 服务里，基础库（standard）器件通常不额外收取上料费用，
> 扩展库（extend）器件按型号收取一次性上料费。当同规格有多个候选时，库别往往比单价更影响
> 小批量的总成本。所以候选表里必须给出这一项。

### 供货

- 采购渠道：〈例如：立创商城 / 嘉立创 SMT 备料〉
- 最低库存要求：〈例如：现货库存 ≥ 目标批量的 3 倍〉
- 生命周期要求：〈例如：不接受 NRND / EOL 状态的型号〉

### 其它

〈例如：需与既有设计的某个封装保持一致；或需要同封装的第二货源〉

## 检索与证据要求

这一节是硬约束，不满足则调研作废。

1. **每个候选必须给出可查证的供应商编号**（例如立创 C 编号）与**厂商型号（MPN）**。
   两者缺一不可 —— 供应商编号用于下单与库匹配，MPN 用于在厂商侧核对参数与生命周期。
2. **每个参数结论必须能追到数据手册。** 给出厂商数据手册的来源（页面链接或文档编号 + 版本/日期），
   并注明关键参数在手册中的位置（章节或表名）。不要转述二手参数页作为唯一依据。
3. **库存与价格必须标注读取时间**，因为它们随时会变。写清是哪个渠道的库存。
4. **严禁凭记忆给出供应商编号。** 编号必须来自本次实际检索的结果。
   任何一条你没有实际检索命中的编号，都必须标记为「未核验」并单列，不得混进主结论。
   编号的最终确认按 `part-number-verification.zh.md` 的清单执行。
5. **参数不达标就说不达标。** 如果检索范围内没有完全满足规格的器件，
   如实说明差在哪一项、差多少，并给出「放宽哪一条约束即可解决」的建议。
   不要为了凑一个答案而悄悄降低标准。
6. 区分**你查到的**和**你推断的**。推断出来的结论要显式标记，并说明推断依据。

## 输出格式

### 一、结论

用两三句话说明推荐哪一个、为什么。如果规格无法被完全满足，在这里第一句就说清楚。

### 二、候选对照表

至少给出主选 1 个、备选 2 个。逐项对照，不要只给结论值：

| 项目 | 主选 | 备选 A | 备选 B |
|---|---|---|---|
| 厂商型号（MPN） | | | |
| 厂商 | | | |
| 供应商编号 | | | |
| 封装 | | | |
| 〈关键参数 1〉 | | | |
| 〈关键参数 2〉 | | | |
| 〈关键参数 3〉 | | | |
| 工作温度范围 | | | |
| 库别（基础库/扩展库） | | | |
| 上料费影响 | | | |
| 单价（注明批量与时间） | | | |
| 库存（注明渠道与时间） | | | |
| 生命周期状态 | | | |
| 数据手册来源 | | | |

对照表里的每一格都要填。确实查不到的填「未查到」，不要留空，也不要写「约」「大概」。

### 三、选择理由

说明主选相对备选的优势，落在具体参数或成本上，不要用「性能更好」这类无信息量的表述。
如果主选是在某一项上做了妥协换来的，明确写出妥协的是哪一项。

### 四、风险与备注

- 单一货源风险、生命周期风险、库存波动风险。
- 参数余量：关键参数距离规格边界还有多少。余量不足的项要点名。
- 装配风险：封装是否需要钢网或炉温调整、是否有立碑/空焊倾向。
- 替换性：主选缺货时能否直接换备选（引脚兼容？参数等效？需要改板吗？）。

### 五、待确认问题

需求规格里没写清、但会影响结论的点，在这里逐条列出。
每条给出「如果按 X 理解，结论是 A；按 Y 理解，结论是 B」，方便一次问清。

### 六、未核验项

本次没有实际检索命中、仅凭印象提到的任何编号或参数，全部列在这里。
这一节可以为空，但不能省略。

## 交接

调研结论确认之后，把主选的字段填进 BOM，交给后续的网表流程：

| BOM 列名 | 取值 |
|---|---|
| `Designator` | 位号 |
| `Footprint` | 封装名 |
| `Value` | 电气值（阻值/容值/电压等） |
| `Manufacturer Part` | 厂商型号（MPN） |
| `Supplier Part` | 供应商编号（立创 C 编号） |

`Supplier Part` 是整条链路的关键字段 —— 后续导入按它查库放器件，填错会放上错器件且事后无法修正。
落 BOM 之前必须先过 `part-number-verification.zh.md` 的核验清单。
